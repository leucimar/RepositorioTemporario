# Consultor Inteligente de Carreiras em TI

Atividade 08 — Inteligência Artificial — UNIPAC Barbacena.

Aluno: Leucimar Tiago da Silva Carvalho.
Professor: Felipe Roncalli de Paula Carneiro.

## Objetivo

Desenvolver um sistema especialista em Python com Experta e interface Streamlit para recomendar, com justificativas, uma entre dez trilhas de carreira em TI.

## Etapas planejadas

1. Engenharia de conhecimento e matriz de decisão.
2. Base de fatos e motor de inferência com regras cruzadas.
3. Entrevista dinâmica e interface web.
4. Validação com personas e testes.
5. Documentação de instalação, execução e limitações.

## Organização Git

- `main`: versões estáveis.
- `develop`: integração.
- `feature/01-conhecimento`: matriz e contrato da entrevista.
- `feature/02-inferencia`: fatos, regras e recomendação.
- `feature/03-interface`: interface Streamlit.
- `feature/04-validacao`: personas e testes.
- `feature/05-documentacao`: guia de uso e rastreabilidade.

Este commit inicia o projeto. As funcionalidades serão integradas nas etapas seguintes.
